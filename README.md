# NIATOLIP (nom de travail)

Outil web agentique de création de cartes PCB : l'utilisateur décrit sa carte en langage naturel, un agent IA la conçoit, la vérifie et la corrige en boucle, avec preview PCB/schéma/3D en direct, puis export des fichiers de fabrication.

Stack validée : **tscircuit + Vercel AI SDK + Meta Model API / OpenAI**. Périmètre MVP : cartes 2 couches basse vitesse (ESP32/RP2040/STM32), composants sourcés JLCPCB.

La documentation produit et technique fait foi : voir [`docs/README.md`](docs/README.md).
